# Image-Captioning-Model-Using-CNN-and-LSTM

Image Captioning using CNN and LSTM

This project implements an image captioning model that automatically generates textual descriptions for images. It uses a Convolutional Neural Network (InceptionV3) as an encoder to extract image features and a Long Short-Term Memory (LSTM) network as a decoder to generate captions. The model is trained on the Flickr8k dataset, which contains images with multiple human-annotated captions. Users can input an image, and the system will display the image along with a generated caption. This project demonstrates the integration of computer vision and natural language processing techniques in deep learning.
